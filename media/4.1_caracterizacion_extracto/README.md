# Catálogo Visual: Caracterización del Extracto de Agave (4.1)

Este directorio contiene la evidencia fotográfica del procesamiento de las pencas de *Agave marmorata* para la obtención del extracto base utilizado en las formulaciones del champú.

| [`extraccion_jugo_crudo.jpg`](./extraccion_jugo_crudo.jpg) | Troceado del parénquima y procesamiento para la separación del jugo crudo de la fibra del agave. | Evidencia complementaria. |
