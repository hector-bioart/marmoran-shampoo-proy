# Resumen de Hallazgos: Caracterización Fisicoquímica (4.1)

Este directorio contiene las representaciones gráficas finales de los parámetros fisicoquímicos evaluados en el jugo crudo estabilizado de *Agave marmorata*.

## Gráficas y Conclusiones Científicas

| Archivo | Visualización | Conclusión Científica |
| :--- | :--- | :--- |
| [`4.1a_barras_ph.png`](./4.1a_barras_ph.png) | Gráfico de barras del Potencial de Hidrógeno (pH) con su respectiva desviación estándar. | Confirma un pH marcadamente ácido (4.03 ± 0.15) propio de los ácidos orgánicos del agave. Este valor es idóneo para la formulación, ya que otorga propiedades de sistema amortiguador (*buffer*) natural al champú. |
| [`4.1b_barras_sdt_conductividad.png`](./4.1b_barras_sdt_conductividad.png) | Gráfico comparativo entre los Sólidos Disueltos Totales (ppm) y la Conductividad Eléctrica (µS/cm). | Los altos niveles en ambos parámetros indican una fuerte presencia de iones y metabolitos solubles en la base acuosa. Esto verifica la eficiencia del proceso de extracción del parénquima, asegurando una concentración importante de principios activos (como las saponinas). |
